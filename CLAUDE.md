# Zenju Weddings

Website for **Yanicke**, a wedding planner, built by Gatherwise.

- `BRIEF.md` is the source of truth for scope, inspiration, brand, and the chosen design direction. Read it before making design or content changes, and update it when decisions change.
- Workflow and phases: the `gatherwise-website-build` skill. Say "continue the GatherWise website build" to resume.
- Stack: Next.js App Router, TypeScript, Tailwind. Design tokens live in `src/app/globals.css`, fonts in `src/app/layout.tsx`, sections in `src/components/sections/`.
- Deploys: pushing to `main` deploys to production on Vercel (project `zenjuweddings`, team `gatherwiseio`). Only push after the user has approved the change, and run `npm run build` first.
